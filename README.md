# Everelia

The Everelia brand website.

Everelia provides **technology management, technology consulting,
helpdesk & support, and hardware management** for growing organizations —
one accountable partner, from day-to-day operations through to strategy.

## Contents

- `index.html` — single-page marketing landing (self-contained; the only
  external dependency is Google Fonts). Features a "Request more
  information" call-to-action with a pre-filled email form.
- `IDEA.md` — short business-context note.

## Design

Warm off-white canvas, deep teal-green primary accent, copper secondary
accent, serif display (Fraunces) paired with a grotesque body (Manrope).
CSS-only scroll reveals, fully responsive, and respects
`prefers-reduced-motion`.

## Deploy

`index.html` is at the repository root, ready to serve as the site's
landing page (e.g. via GitHub Pages).
